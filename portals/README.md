# portals

Static web apps, built here and served by the Manager.

| Path | App |
|---|---|
| `admin/` | Admin Portal: engine, deployed integrations, users and roles (ported from ICP's workflow pages, login, SSO and access-control screens) |
| `user/` | User Portal: the human-task inbox only |
| `shared/` | Components both apps use: sign-in, task form, layout |
